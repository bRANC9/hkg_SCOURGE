# jlink module set for the headless Java 25 runtime.
#
# java.se gives the full standard-edition API surface without the compiler.
# The jdk.* modules below are the parts daemons commonly need at runtime:
# HTTP server, extended sockets, zipfs, charsets/locales, crypto, JMX,
# attach/diagnostics (jcmd), JFR and remote debugging.
#
# Do not add jdk.compiler/jdk.javadoc/jdk.jlink here.  The default package is
# a runtime, not an on-car SDK.  JAVA_EXTRA_MODULES in build_payload.sh is the
# supported way to build a larger variant.
java.se
jdk.unsupported
jdk.crypto.ec
jdk.crypto.cryptoki
jdk.httpserver
jdk.net
jdk.nio.mapmode
jdk.zipfs
jdk.localedata
jdk.charsets
jdk.jfr
jdk.jcmd
jdk.management
jdk.management.agent
jdk.management.jfr
jdk.attach
jdk.jdwp.agent
jdk.security.auth
jdk.security.jgss
jdk.naming.dns
jdk.naming.rmi
jdk.xml.dom
